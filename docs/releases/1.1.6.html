Copas 1.1.6

Fixes the clipboard board sometimes not opening after Copas has been running for a long time.

  • Board Reliability: The board now checks whether its window is really on screen instead of trusting a remembered state, ignores stale app-switch events, and rebuilds its hidden window after sleep and wake, Space changes, or display changes.
  • Writing Tools: A stuck Writing Tools state can no longer keep the board from opening.
  • Diagnostics: The board now logs why it opens and closes, which makes any recurrence easier to track down.
