Copas 1.0.7

A stability and performance update resolving a UI freeze and refining color filters.

  • Asynchronous App Icon Resolution: App icon lookups for clips now resolve in the background off the main thread. Even if macOS LaunchServices takes time to query custom or cloned application bundles, the Copas board remains completely fluid and responsive with zero UI stalling.
  • Refined Colors Filter: The Colors smart filter now strictly targets actual color values (hex codes like #FF5733, #fff, and CSS functions like rgb(), hsl()), preventing Markdown notes and headings starting with # from being mistakenly categorised as colors.
  • Filter Empty State: When a filter has no matching clips, the board now shows a helpful "No clips match" search empty state rather than "Nothing copied yet".

Your clips, settings and shortcuts are untouched by this update.
