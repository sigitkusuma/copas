Copas 1.0.12

A focused release bringing media canvas drag-and-drop support for photo and graphic editors, improved copy button interaction and persistence, and automated release signing stability.

  • Drag & Drop to Media Canvases (Photoshop, Figma, Pixelmator): Image clips can now be dragged directly onto image canvases, creative tools, and graphic editors without drag gesture conflicts or invalid metadata rejections.
  • Copy Button Reaction & Window Persistence: Clicking the Copy button in the detail view now triggers immediate HUD feedback and leaves the clipboard board open for uninterrupted workflow rather than unexpectedly closing.
  • Sparkle Automation Stability: Headless release pipeline improvements ensuring automated appcast signing and publication without keychain modal lockups.

Your existing clips, settings, and database are preserved seamlessly.
