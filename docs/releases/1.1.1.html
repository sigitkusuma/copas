Copas 1.1.1

Hotfix release resolving application launch and sync menu issues on macOS.

  • Launch Fix: Removed restricted developer entitlements that caused macOS AMFI (Apple Mobile File Integrity) to terminate the app on launch without an embedded provisioning profile ("The application 'Copas' can't be opened").
  • Sync Menu Crash Fix: Added entitlement capability validation before initializing CloudKit, preventing fatal framework assertions when opening or enabling the Sync settings without a provisioning profile.
  • Stability: Restored normal launch behavior and ensured safe fallback in settings while keeping all clipboard history, local database migrations, and existing features intact.
