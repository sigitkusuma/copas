Copas 1.0.11

A stability, drag-and-drop, and Apple Intelligence refinement release resolving external image dragging, Writing Tools regeneration locks, text selection affordance dismissal, and dynamic cursor-following capture feedback.

  • Native Image Drag & Drop to Finder and Outside Apps: Image clips can now be dragged directly out of the clipboard list or detail preview into Finder folders, Desktop, Mail compose windows, Slack, Discord, web browsers, and any application expecting a native file URL.
  • Writing Tools Regeneration Stability: Fixed an issue where regenerating text with Apple Intelligence Writing Tools on macOS 15+ could freeze the text editor. Synchronized Writing Tools lifecycle events cleanly to protect editor state and prevent animation deadlocks.
  • Apple Intelligence & Siri Affordance Focus Handling: Selecting text in the editor and clicking the inline Apple Intelligence / Siri icon or context menu no longer inadvertently dismisses the clipboard panel.
  • Contextual "Text Copied" HUD: The capture completion pill and progress toasts now appear anchored right next to the selected screen region or mouse cursor on the active display, rather than fixed at the bottom of the primary monitor.
  • Instant Copy Feedback: Clicking the Copy button in the detail pane now provides immediate visual confirmation with a checkmark badge.

Your existing clips, settings, and database are preserved seamlessly.
